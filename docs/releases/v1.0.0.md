# HOK Broadcast v1.0.0

发布日期：2026-10-07

这是 HOK Broadcast 的第一个正式版本。v1.0.0 的目标是把此前分散验证的导播、延迟解说、OBS Overlay、Auto BP、BP Simulator 和最终阵容功能整理成一套可以实际用于社区赛事彩排的工作流。

## 主要功能

### 导播与比赛状态

- Control / Caster / Overlay 三端同步。
- BO1 / BO3 / BO5。
- Match BP（每队 4 Ban）与 Normal BP（每队 2 Ban）。
- 蓝/红先手。
- Normal / Player / Global 三种 BP 规则。
- Undo、重置 BP、重置整场比赛。
- 延迟 Caster 数据时间线。
- 队伍资料库、首发、替补、照片和快速换人。
- 两种 OBS Overlay 布局。

### Auto BP

- 浏览器窗口采集。
- 蓝/红双方 4 Ban + 5 Pick，共 18 个独立识别框。
- 全屏精细校准。
- 18 框命名预设，支持保存、载入、覆盖和删除。
- Pick 双选 Turn。
- 普通 Pick 通过下一位对手开始预选确认上一轮锁定。
- Pick→Ban 边界和最后一手使用选角高亮恢复作为 fallback。
- Ban 圆形头像 mask。
- Ban 锁定 cue。
- 空 Ban 保护与人工确认。
- 自动监视。
- 自动锁定判断失败时可用“手动确认当前最高候选”直接审核当前最高相似度英雄/英雄组。
- 屏幕识别模式保留折叠式手动英雄选择器作为最终 fallback。

### 最终阵容与换英雄

- BP 历史与最终阵容归属分离。
- BP 完成后扫描 10 个 Pick 槽。
- 每队只在本队 5 个已 Pick 英雄中求最终分配。
- 稳定检测到英雄互换后自动同步最终阵容。
- 支持“立即识别并应用换英雄”。
- 支持人工下拉修正。

### 英雄数据与图片

- 当前英雄池由 Hero Data Synchronizer 维护。
- 中英文、alias 与搜索。
- 英雄图片/数据运行时 override。
- 英雄数据编辑器采用可搜索的头像网格，不再依赖超长下拉列表。
- Panel / Side 图片裁切与预览。
- Flowborn 形态合并/独立规则。

### BP Simulator

- 独立控制页与干净采集页。
- Match / Normal BP。
- 蓝/红先手。
- 圆形 Ban、空 Ban、Pick 高亮、双选。
- 完整 18 phase 流程。
- 选手互换英雄。
- 自动脚本会连续推进整个 BP。
- 自动脚本支持最短/最长随机等待范围。
- Windows 一键后台启动，启动窗口自动关闭。
- 新增 `stop-bp-simulator.bat`。

## 性能与访问流程更新

- 各角色快照缓存和延迟事件二分查找。
- 识别计算减少中间图片编码、重复裁剪和重复画面计算，保留多裁剪结果。
- 模拟器随机选角共用 Control BP 规则，锁定后固定 120ms 切换。
- 识别自动输入可配置 50%–100% 相似度阈值；默认关闭。
- 英雄高级数据折叠、Overlay / Simulator 画布缩放。
- 导播管理远程密码及随机角色 token，本机验证免登录，Overlay 增加登录窗口。
- 预留版本化识别 API 与未来 AI 提供者接口。

## v1.0.0 现场推荐流程

1. 使用 BP Simulator 先完成一次完整识别测试。
2. 校准真实比赛画面的 18 个框并保存预设。
3. 完整走一次 Match BP。
4. 测试至少一次双 Pick、一次空 Ban和一次换英雄。
5. 检查 Caster 延迟。
6. 在 OBS 中检查 1920×1080 Overlay。
7. 测试浏览器刷新和服务器重启恢复。
8. 正式比赛前再对真实游戏版本进行一次 Ban/Pick 素材验收。

## 已知边界

- 图像识别依赖实际游戏 UI、头像裁切、亮度、缩放和版本；新的游戏 UI 可能需要重新校准。
- Ban 锁定视觉特征来自当前测试素材，游戏更新后应重新验证。
- Pick 的自动锁定判定有人工最高候选 fallback，不建议把自动识别当成不可人工干预的黑盒。
- 18 框预设保存在 Director 浏览器 localStorage，不会自动跨电脑同步。
- Caster 延迟是数据延迟，不是视频平台延迟。
- Cloudflare Quick Tunnel 地址每次启动可能变化。
- OBS、直播平台、远程解说和 Discord 的完整端到端音画同步仍需要现场彩排。

## 推荐环境

- Windows 10/11
- Node.js 24 LTS
- Microsoft Edge 或 Google Chrome
- OBS Studio
- cloudflared（需要 Quick Tunnel 时）

## 升级

从近期开发版本升级到 v1.0.0 时：

1. 拉取最新代码；
2. 在 `vite-project/` 运行 `npm ci`；
3. 运行 `npm run build`；
4. 重启 Broadcast；
5. 刷新 Director / Caster / OBS Browser Source；
6. 保留并备份 `vite-project/data/`；
7. 重新检查 Auto BP 的 18 框预设。

不要把旧版本的 `node_modules` 当作发布包的一部分。
